Bloom Bites NYC — Matcha Cafe Landing Page

A responsive, floral-inspired landing page for Bloom Bites NYC, a matcha cafe and bakery. Built with clean HTML and CSS, featuring soft earthy tones, cherry blossom accents, and a responsive layout across desktop and mobile screens.

Features

Header & Navigation: Includes the BloomBites Cafe logo, a search bar, navigation links (Shop, Categories, About, Contact), a "Join Our Community" CTA button, and a mobile-friendly navigation menu.

Hero Section: Showcases the tagline "A Quiet Bloom in Every Sip" paired with floral accents, a featured matcha latte image, and quick action buttons (Order Online and Visit Bloom Bites).

Featured Matcha Bakes: A clean 2x2 product grid highlighting signature pastries with pricing (Matcha Raspberry Blossom Macarons, Pistachio Garden Macarons, Matcha Almond Dipped Croissants, and Matcha Snow Peak Danish).

NYC Branches Section: Displays the top Bloom Bites locations (SoHo, BK Lounge, and Lab) in arched cards with quick location buttons.

Order & Gifting Banner: Full-width matcha swirl banner with options to Send a Gift Box or Schedule a Delivery.

Footer: Contains quick navigation links, social/contact icons, and copyright details.

Technologies Used

HTML5 — Semantic page structure

CSS3 — Flexbox, CSS Grid, custom typography (Oswald & Space Mono), and responsive @media queries

Font Awesome — UI and social media icons
